# 论文 LaTeX 源码（复现说明）

本目录是论文的 LaTeX 源码，与 `code/`、`figures/`、`tables/` 共同构成支撑材料。

| 文件 | 说明 |
|---|---|
| `main.tex` | 正文主文件：摘要与关键词、一～十章、AI 工具使用声明、参考文献 |
| `appendix.tex` | 附录 A 支撑材料文件列表、附录 B 移出正文的图表、附录 C 核心源程序（摘录） |
| `appendix_moved.tex` | 附录表 D1～D11 与附录图 D1～D6 |
| `ai_usage.tex` | 支撑材料《AI 工具使用详情.pdf》的源码 |
| `appendix_code_excerpt/` | 附录 C 收录的 5 段核心算法摘录（主策略、全域检出证书、建证集、L2/L3 审计、问题一与二数值实验） |

> 附录 C 按“只放核心算法”的口径收录摘录；**建模所用全部 46 个脚本的完整可运行版本见 `../code/`**。

## 编译方式（XeLaTeX，连编两遍）

1. 把 `../figures/` 下的全部图片复制为本目录下的 `figures/` 子目录；
2. 执行 `xelatex main.tex` 两次（第一次生成交叉引用，第二次定稿页码）。

## 说明

- 论文 PDF 即由本目录源码编译得到：摘要页 1 页、正文（含 AI 工具使用声明与参考文献）29 页、附录 20 页，共 50 页；正文按国赛口径不超过 30 页，附录页数不限。
- 论文插图与数据表分别见 `../figures/`、`../tables/`；完整可运行源程序见 `../code/`。

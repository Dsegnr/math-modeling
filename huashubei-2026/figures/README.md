## 图注建议

- q1_group1_3d.png：图 N 组1 微构体的介质 A 构型与连通簇分布（XYZ 单位：nm；红/蓝面为带电面；不同颜色为不同连通簇，灰色为其余段；XY 俯视图见右下）。组1 中不存在同时接触左右带电面的连通簇，判定为不导通。
- q2_p_phi_curve.png：图 N 介质 A 导通概率随体积分数的变化（误差棒为 95% Wilson 置信区间；虚线为 90% 可靠性目标）。导通概率在 0.6%~1.2% 区间快速上升，呈现典型渗流相变特征。
- q3_fit_curve.png：图 N 渗透模型拟合与 φ* 双方法互证（两条拟合曲线在 P=90% 附近几乎重合；三色竖线分别为拟合反解、概率二分与细化定稿的 φ*）。
- q4_contour.png：图 N A+B 混合体系导通概率曲面与成本最优解（红色实线为 P=0.90 可行边界；紫色三角、橙色方块与绿色星号分别为 LP 极点、2D 代理优化与最终验证最优，右上为候选点局部放大）。
- q1_data_overview.png：图 N 附件行长度分布（红色虚线为标称行长 5000 nm）。三组行距均不恒为 5000 nm，且大量行在 5000 nm 处截断堆积，说明附件按边界截断后的分段存储。
- q1_boundary_example.png：图 N 组1 第 1 行与第 12 行的周期镜像共线关系（两段端点的 (y,z) 坐标完全相同、方向向量成比例），是“同一根圆柱被边界切为两段”的直接数据证据。
- q2_cluster_sizes.png：图 N 渗流簇大小分布（对数轴）。随体积分数增大，最大簇占比从 57% 升至 84%，小簇被逐步吞并，体现渗流相变的结构演化。
- q4_pure_curves.png：图 N 介质 A 与介质 B 的导通效率对比。介质 A 在 φ*=1.36% 时达到 90% 可靠性（成本 14.27 元），介质 B 在 61% 时导通概率约 90% 但仍不满足 CI 下界规则（成本 30.71 元），球形介质存在“面接触瓶颈”。
